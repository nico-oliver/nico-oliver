### Hola, soy Nicolás Oliver

Implanto IA y automatizo procesos en pequeñas empresas: software a medida que se usa a diario, no demos.

**Qué hago**

- **ERP a medida en producción** para un comercio minorista: compraventa, inventario, clientes y obligaciones legales del sector, en uso diario por el equipo de la tienda. TypeScript, Next.js y PostgreSQL. *(Código privado: es del cliente.)*
- **Automatización sobre Google Workspace**: cinco módulos en Apps Script en producción en el día a día de un negocio.
- **Webs escaparate** rápidas y estáticas con Astro, desplegadas en Cloudflare Pages.
- **Herramientas propias para trabajar con agentes de IA**: paneles y visualizadores de sesiones de Claude Code, transcripción de voz en local y asistentes por Telegram.

**Con qué trabajo**

TypeScript · Next.js · PostgreSQL · Python · Google Apps Script · Astro · Godot · Claude Code y la API de modelos de IA

**Proyectos públicos**

- [Torre de Control](https://github.com/nico-oliver/torre-de-control): panel local que muestra qué sesiones de Claude Code y Codex trabajan ahora, en qué proyecto y qué está esperando una decisión.
- [Claude Office](https://github.com/nico-oliver/claude-office): oficina en pixel art donde cada sesión de Claude Code del PC es un personaje.

**En mi tiempo libre** publico como [VoltorDev](https://github.com/VoltorDev) mods y addons para videojuegos, con usuarios en plataformas de mods, y un juego web cooperativo. El empaquetado y la publicación están automatizados, con comprobaciones antes de cada subida.
